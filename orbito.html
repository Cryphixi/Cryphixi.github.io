02 / GamesCrafters / Case study

Orbito: Designing a Two-Phase Turn

Turning a rotating physical board game into a click interface that still feels real, on top of a solver covering 20M+ positions.

← All work

01 / The problem

Who needed a better experience?

A physical Orbito turn includes rotation and an optional second phase. The digital interface has to explain both the action and the possibility of skipping without making the player read a rulebook mid-turn.

02 / Process

From observation to iteration

The team first built a text interface to prove the solver, then moved to a graphical interface on GamesmanUni. The interaction question became how to expose an optional second phase so players know they can skip it. [ADD TURN FLOW DIAGRAM AND ITERATION SCREENSHOTS]

03 / Decisions

What shaped the design

Prove behavior first

A text interface established the solver before graphical choices were layered on top.

Keep the turn legible
